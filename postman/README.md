# Postman — CIP Backend

## Cursor / Postman Local View

**CIP Backend** should appear under Local Items from `collections/CIP Backend/`.

If missing: Postman sidebar → refresh, or reload the window.

## Postman Desktop

Import `CIP_Backend.postman_collection.json` (single portable file).

Set `baseUrl` to AppSail (default) or `http://127.0.0.1:8000`.
